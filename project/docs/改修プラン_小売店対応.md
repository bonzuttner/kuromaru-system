# 大改修プラン（小売店マスタ導入 + 発送リスト画面）

## ユーザー回答（m0103, m0107）
- 小売店マスタを追加し、店舗・商品・黒丸表・発送情報を**小売店ごとに完全分離**
- ヘッダーに小売店プルダウン。ナビはハンバーガーメニュー化
  - 階層表示: 「小売店 > 黒丸表 > 発送情報」 と 「マスタ」
- 発送情報画面 → **発送リスト（帳簿）入力 + CSV出力**画面に作り替え（旧発送帳簿画面は削除してよい）
- 1行 = 1店舗 × 1商品
- CSV出力は UTF-8（BOM付き推奨）
- 各マスタに不足項目を追加（下記xlsx仕様の参照元に従う）
- 現ファイル「黒丸表システム v2.dc.html」はユーザー直接編集あり → 編集前に再読込必須

## xlsx仕様（uploads/hassou_spec.xlsx「帳簿データ整理」）
CSV列36項目・順序: MKCD,DATC,DENYMD,DENNO,GYONO,TOKCD,TOKNM,TOKBNM,TKPOST,TKTEL,TKFAX,TKADD1,TKADD2,TKADD3,HAICD_1,HAICD_2,HAINM,HAIBNM,HAPOST,HATEL,HAFAX,HAIADD1,HAIADD2,HAIADD3,SYOCD1,SYOCD2,SYONM,JAN,ITF,IRISU,PRICE,GENKA,SKSU,SYUYMD,MKNM,CR

### 参照元=小売店マスタ（F列「小売店」の行）→ 小売店マスタの項目
- MKCD メーカーコード（デフォルト999・重複可）
- TOKNM 得意先名（=小売店名）
- TKPOST 郵便番号 / TKTEL 電話番号 / TKFAX FAX（任意） / TKADD1 住所1
- TOKBNM 得意先部署名（任意・小売店マスタで保持）
※小売店マスタ項目: 小売店名, メーカーコード(999), 部署名(任意), 郵便番号, 電話, FAX(任意), 住所1

### 参照元=店舗マスタ（F列「店舗」）→ 店舗マスタに追加する項目
- HAICD_1 配送先コード1（任意・デフォルト0）
- HAIBNM 配送先部署名（任意）
- HAFAX FAX（任意）
- 既存: HAINM=店舗名称, HAPOST=郵便番号, HATEL=電話, HAIADD1=住所

### 参照元=商品マスタ（F列「商品」）
- SYOCD1 商品コード（既存の商品ID）
- JAN JANコード → **商品マスタにJANコード項目を追加**（現状は配送情報にある）
- SYONM = 商品コード & イベント名 & 商品カテゴリ & 黒丸表番号 & 商品名 を連結
  - イベント名デフォルト「販促POP」（発送リスト作成画面で入力）
  - 例: 「0201販促POP 目薬①スマイルTHE ONE」→ 黒丸表番号=①等の丸数字
- MKNM メーカー名: 小売店別発送設定（帳簿の全行一律・小売店ごとに変更可能に保持）

### 発送リスト作成画面で入力する項目
- DATC データ区分（デフォルト2・小売店ごとに保存して再利用）
- DENYMD 伝票日付（手入力 → YYYYMMDD変換）
- GYONO 行番号（デフォルト1・画面で変更可）
- TOKCD 得意先コード（空欄可・画面入力）
- イベント名（SYONM連結用・デフォルト「販促POP」）
- MKNM メーカー名（小売店ごと保存）

### 自動/固定
- DENNO 1からの連番（システム）
- SYUYMD = 配送情報の「店舗着」→YYYYMMDD
- SKSU=1固定, HAICD_2=0固定, TKADD2/3・HAIADD2/3・SYOCD2・ITF・IRISU・PRICE・GENKA=空欄, CR="CR"固定
- 行の生成元 = 全黒丸表の●（1行=1店舗×1商品）

3. ヘッダー: 小売店プルダウン + ハンバーガーメニュー（小売店>黒丸表>発送情報 / マスタ の階層表示）
